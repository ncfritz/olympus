# Code generators

`pnpm gen <generator>` runs a Turborepo generator from this directory.

| Generator       | Status                                    | Purpose                                                         |
| --------------- | ----------------------------------------- | --------------------------------------------------------------- |
| `api-operation` | planned, lands with the `apps/api` import | Scaffolds one API operation following `docs/conventions/api.md` |

The design is in `docs/guides/api-operation-generator.md`.
